1. Press Windows + R.

2. Enter:
   \\MobileZone

3. Press Enter.

4. If Windows asks for credentials:
   Username: MobileZone\YOUR_WINDOWS_USERNAME
   Password: YOUR_WINDOWS_PASSWORD

5. A window will appear showing:
   AVICAR PL01A

6. Double-click AVICAR PL01A.
   Windows will install/connect to the shared printer.

7. Go to:
   Control Panel → Devices and Printers

8. Verify that AVICAR PL01A appears.

9. When printing from the browser, use:
   Paper size: 72 mm × 297 mm
   Scale: 100%
   Margins: None
   Headers and footers: Off

The printer itself remains connected by USB to the server PC:
MobileZone → USB → AVICAR PL01A
